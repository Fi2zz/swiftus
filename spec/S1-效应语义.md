# S1 · 效应语义（core）

版本：v1.0 · 日期：2026-09-27 · 来源：conatus_core `effect_scope.dart` / `reactor.dart`
语言中立规格。Swiftus 实现注记见文末。

## 1. 撤销函数（Disposer）

- 每次施加副作用可同时登记一个撤销函数；调用它应使系统恢复到副作用施加之前的状态。
- 同一个 Disposer 可能被多次调用（作用域释放后又手动调用），实现必须幂等。

## 2. EffectScope（时间可组合性）

收集一组可逆副作用，按 LIFO（后进先出）顺序统一撤销。

- **LIFO**：`dispose()` 按登记逆序执行全部撤销函数。
- **幂等**：重复调用 `dispose()` 只真正释放一次；第二次起返回空错误列表。
- **迟到登记安全**：作用域已释放后再 `track(disposer)`，该撤销函数**立即执行**（不丢弃、不泄漏）。
- **抗异常**：单个撤销函数抛错不阻断其余撤销；`dispose()` 收集全部错误并返回（空列表 = 全部成功），自身不外抛。
- `disposed`：是否已释放；`length`：当前登记的撤销函数数量。
- `capture(body)`：执行 body；若其返回值是 Disposer，则自动登记，原样返回该值。

## 3. Reactor（空间可组合性调度核心）

服务变更的同步广播器，采用「脏标记 + 重跑」策略处理重入。

- `add(listener)`：登记监听器；同一函数可被重复添加，每次登记是一个独立实例。
- `remove(…)`：移除一个已登记的实例，返回是否确实移除了一个。
- `notify()`：
  - 若当前无广播进行：开始广播，快照遍历监听器列表（监听器在回调中增删列表不引发并发修改错误）；
  - 若当前已有广播进行中（重入）：仅设置脏标记并立即返回，由最外层广播循环负责再跑一轮；
  - 每轮结束后若脏标记置位则再跑一轮，直到一轮下来无新脏标记（收敛）；
  - **重入收敛快速失败**：`maxRounds`（默认 100，必须为正整数）限制单次 `notify()` 的最大轮数；超过则抛错——意味着存在循环依赖（A 的激活依赖 B，B 的激活又依赖 A）。
- `running`：是否正在广播中；`length`：已登记监听器数量。

## 4. 不变式

1. 同一棵上下文树共享同一个 Reactor（见 S2），服务变更的广播对整树同步生效。
2. 收敛性靠「快照遍历 + 整列重跑」保证：依赖链 `A → B → C` 在一次 `notify()` 内一次性稳定，调用方无需手动编排顺序。
3. Disposer 幂等性由登记方与实现方共同保证：任何路径下重复调用的可观察效果不超过一次。

## Swiftus 实现注记（偏离记录）

- **错误兜底**：Dart 用 Zone 兜底未捕获错误，Swift 无对应物。EffectScope 的「抗异常收集」完整保留（Disposer 类型允许抛出）；非收集路径（迟到登记的立即执行、Context 释放尾部的兜底广播）的错误改投到域级 `uncaughtErrorHandler`（默认输出到 stderr，测试可替换）。
- **监听器移除**：Dart 以闭包身份移除（`List.remove`），Swift 闭包无相等性，改为 `add` 返回 `ListenerToken`、`remove(token)` 移除单个实例；「同一函数可重复添加、每次移除一个实例」语义不变。
- **`maxRounds <= 0`**：Dart 抛 `ArgumentError`；Swift 以 `precondition` 快速失败（编程错误，非可恢复错误）。
- **非收敛抛错**：`notify()` 为 throwing；`provide` 等直接调用路径原样传播（与 Dart 一致），Disposer 内的调用由 EffectScope 收集或投入 `uncaughtErrorHandler`。
- **隔离模型**：整棵上下文树绑定单一全局串行 actor（`@ContextTreeActor`），对应 Dart isolate 的单线程语义；域内调用全部同步，域外访问经编译期隔离检查，不使用 `@unchecked Sendable`。
