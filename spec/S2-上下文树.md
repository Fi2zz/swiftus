# S2 · 上下文树（core）

版本：v1.0 · 日期：2026-09-27 · 来源：conatus_core `context.dart`
语言中立规格。Swiftus 实现注记见文末。

## 1. 上下文与树

- `Context` 同时承载**效应**（S1：track / effect / onDispose，随释放撤销）与**共效应**（provide / inject）。
- 上下文组成一棵树：`Context.root(name:)`（默认名 `root`）创建根；子上下文由 `inject` / `plugin` 派生。
- **整棵树共享同一个 Reactor**（根创建，子级沿用），服务变更对整树同步广播。
- 属性：`name`（调试用）、`parent`（根为 nil）、`disposed`、`localServiceKeys`（本上下文直接提供的服务键，不含继承）。
- `description` 形如 `Context(root)`。

## 2. 服务（空间可组合性的载体）

服务以字符串键标识，查找沿父链向上：

```
root ──┬── pluginA ──┬── sub1
       └── pluginB   └── sub2
```

- **可见性**：子上下文可见父上下文提供的服务；反之不成立。
- `get(key)`：沿父链查找；本上下文**直接**提供（含提供 nil 值）即短路返回，不再上溯；找不到返回 nil。
- `require(key)`：同 `get`，找不到时抛错（消息形如 `服务 "k" 在上下文 "name" 中不可用。`）。
- `contains(key)`：服务是否可见（含继承）。
- `provide(key, value)`：
  - 上下文已释放 → 抛错（`上下文 "name" 已释放，无法再提供服务 "k"。`）；
  - 同一上下文重复提供同键 → 抛错（`服务 "k" 已在上下文 "name" 中提供。`）；
  - 成功：登记服务并广播（`notify()`）；返回幂等 Disposer——提前手动撤销或随上下文释放自动执行；**撤销时若键位已被后续操作更替，不误删新值**；
  - 允许提供 nil 值：`contains` 为真、`get` 为 nil、`require` 抛错（与「服务不存在」区分）。
- 服务随本上下文释放而自动移除；释放尾部若仍有残留服务（异常路径兜底），一并清除并再广播一次。

## 3. inject（声明式依赖注入）

`inject(deps, callback)`：

- 依赖列表先**去重并冻结**（保持首次出现顺序），调用方后续修改入参不影响语义。
- 登记后立即做第一次评估；此后任一相关服务增减（整树广播）都会再评估：
  - **依赖全部可见且当前未激活**：在**一个全新的子上下文**中执行 callback（子上下文名形如 `host<dep1+dep2>`）；
  - **任一依赖消失且当前已激活**：该子上下文连同其所有效应被整体撤销；
  - **依赖重新齐全**：callback 在另一个全新子上下文中再次执行（不复用旧子上下文）。
- callback 抛错：子上下文回滚（撤销），错误上报（见 S1 实现注记的兜底通道）。
- 返回幂等 Disposer：手动取消注入（移除监听 + 撤销活跃子上下文）；该取消动作同时被登记到宿主上下文，随宿主释放自动执行。

## 4. plugin（组件的加载单元）

`plugin(name, install)`：

- 在派生的子上下文中执行 `install`（子上下文名形如 `Context(root)/name`），返回该子上下文句柄。
- 子上下文登记到当前上下文：父释放时级联卸载（父释放级联子树）。
- `install` 抛错：子上下文回滚，错误继续向调用方传播。

## 5. dispose（生命周期）

- 撤销所有效应（S1 LIFO）、移除所有服务、级联释放派生的子上下文；幂等。
- 释放过程中收集到的撤销错误由释放方丢弃（与 Dart 行为一致：Context 不转发 EffectScope 的错误列表）。

## Swiftus 实现注记（偏离记录）

- **服务键形态**：Dart 为「字符串键 + 运行时泛型」；Swiftus 用 phantom key——`ServiceKey<S>("logger")` 携带类型与字符串 id，`provide` / `get` / `require` 编译期保类型；`inject` 依赖列表用抹型 `AnyServiceKey`（可由字符串字面量构造，与 Dart 侧日志/规格里的键字符串一致）。
- **`has` 改名 `contains`**：遵守布尔命名约束（禁 `is/has` 前缀），语义不变。
- **「不误删新值」的实现**：Dart 用 `identical()` 比对；Swiftus 给每次 provide 配发唯一令牌，撤销时令牌不匹配即跳过，语义等价。
- **`require` 为 throwing**：Dart 抛 `StateError`；Swift 抛 `ContextError.serviceUnavailable`，调用点需 `try`（惯用法取舍，语义同为快速失败）。
- **隔离模型**：见 S1 注记——全树 `@ContextTreeActor` 单域串行，域内同步调用。
