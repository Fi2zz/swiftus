# S12 · 凭据

版本：v1.0（**最小集**：契约 + env / memory 来源；file / vault / aws / SigV4 随 W3 补） · 日期：2026-09-27 · 来源：conatus_credentials
语言中立规格。Swiftus 实现注记见文末。

## 1. Credential 值对象

- 字段：`key`（如 `ARK_API_KEY`）、`value`（明文，**绝不入日志**）、`expiresAt?`（空 = 永不过期）。
- `masked`：脱敏表示，规则见 S3 §2（maskSecret）。
- `expired`：仅当 `expiresAt` 非空且早于当前时刻（过期即视为没有）。
- `toString` 只含键名与 masked，不含明文。

## 2. 错误码（CredentialsException：code / message）

- `missing`：缺少凭据（require / validate）；`read-only`：只读来源被写。
- 预留（W3）：`vault-http` / `aws-http`。

## 3. 来源枚举

`env` / `file` / `memory` / `vault` / `aws`（最小集只实现 env 与 memory）。

## 4. parseCredentialMap（四来源共用的 JSON 解析口径）

输入为动态 JSON 对象，每项两种形态：

- 字符串 —— 直接作为值；
- 对象 —— 读 `value`（字符串，缺则跳过该项）与可选 `expiresAt`（ISO 8601 字符串，解析失败视为无）。

输入不是对象时返回空表；键非字符串、值形态不合法（数字、布尔等）的项一律跳过。

## 5. CredentialSnapshot（内存快照 + 变更广播）

- `get(key)`：不存在或**已过期**返回空。
- `update(credential)`：写入并推送变更；已关闭时忽略。
- `refreshSnapshot(values)`：整体替换快照，并逐一推送**新增或发生变化**的凭据（value 或 expiresAt 不同即变化）；**移除无法表达，不推送**。
- `close()`：幂等；关闭后写入被忽略。
- `keys`：快照中键的不可变副本。

## 6. Credentials 契约

- 读取**同步**（读内存快照）：`get`（找不到或已过期返回空）、`require`（空则抛 `missing`：`缺少凭据 "k"。`）、`validate(keys)`（任一缺失即快速失败，消息列出**全部**缺失键：`缺少凭据：a, b`）。
- `update(key, value)`：**只读来源抛 `read-only`**；可写来源（memory）立即生效并推送。
- `changes`：更新或刷新后的变更广播（消费方按键订阅）。
- `refresh()`：从底层来源重拉快照；默认无操作。
- `close()`：释放来源（取消订阅与定时器）；幂等。

## 7. 来源语义（最小集）

- **EnvCredentials**（只读）：构造时把全部**非空**环境变量装入快照；`refresh` 重读环境映射（测试可注入自定义映射）；`update` 抛 `read-only`（`环境变量凭据是只读来源。`）。
- **InMemoryCredentials**（可写）：`initial` 建初始快照；`update` 立即生效并推送；适合进程内临时凭据与测试替身。

## 8. 装配（provideCredentials）

- 以 `'credentials'` 服务键提供到上下文；缺省为 EnvCredentials；`close()` 随上下文释放登记；同上下文重复提供抛错（沿 S2 provide 语义）。

## Swiftus 实现注记（偏离记录）

- **changes 通道形态**：Dart 为 broadcast `Stream`（异步推送）；Swiftus 在同一串行域（`@ContextTreeActor`）内改为**同步监听列表**（add/removeChangeListener，令牌注销）。消费方与来源同域，无跨线程时序差异；与 Reactor 的广播模型一致。
- **过期判定的时钟**：`expired(now:)` 与快照 `get(_:now:)` 接受注入时刻（默认系统钟），保证测试确定性；待 Clock 统一纪律落地（方案书 §5.5）时回接。
- **ISO 8601 解析**：以 ISO8601DateFormatter 承载，与 Dart `DateTime.tryParse` 的兼容面略有差异（如仅日期无时间的串），暂记。
