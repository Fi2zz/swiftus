# S5 · 工具管线

版本：v1.0 · 日期：2026-09-27 · 来源：conatus_foundation `tool*.dart` / `param_spec.dart` / `parameter_schema.dart` / `tools.dart`
语言中立规格。Swiftus 实现注记见文末。

## 1. 词汇

- `ToolCall`：`name`（注册表键）、`callId`（调用方提供，缺省空串，用于回喂与关联）、`arguments`（解析后的参数对象）。
- `ToolError`：`code`（稳定机器可读错误码）+ `message`；展示形如 `code: message`。
- `ToolResult`：成功携带 `content`（模型可见文本）与可选规范值 `value`；失败携带 `content` 与 `error`。`isError` 区分成败。
- `ToolRisk`：`low`（只读）/ `medium`（有副作用但可回退）/ `high`（破坏性或需确认）。
- `ToolGuard`：单调守卫，返回非空理由即拒绝该次调用。
- `ToolMiddleware`：环绕执行，`next()` 交给后续管线（含执行体）。
- `ToolResultListener`：结果观察者。

## 2. 白名单投影（toSchema）

- `Tool.toSchema()` 只含 `name` / `description` / `parameters` 三键；`riskLevel` / `group` / `timeout` / `pathParams` / 执行体等宿主字段**永不下发模型**。
- `parameters` 由 `params` 声明编译生成（§3 / §4），未声明参数时为 `{type: 'object', properties: {}}`。

## 3. ParamSpec（七类参数声明 → JSON Schema）

- 七类：`string` / `integer` / `number` / `boolean` / `enumeration` / `array` / `object`。
- 单参数 schema 片段：`type`（枚举映射为 `'string'` 并附 `enum` 取值）；`array` 附 `items`（元素声明的递归片段）；`object` 附 `properties`（嵌套字段递归）与**嵌套 required 聚合**（子声明中标记必填的字段名列表，非空才输出）；`description` 与 `default` 为注解（不参与校验）。
- `enumeration` 的取值列表不能为空（空则快速失败）。

## 4. parameterSchema（声明列表 → 顶层 schema）

`{type: 'object', properties: {按声明名}, required: [必填名]}`；无必填项时不输出 `required` 字段。

## 5. 参数校验（validateToolArgs）

按 `Tool.params` 逐条校验，返回违规说明列表（空 = 通过）。消息原文全集：

- 缺必填：`缺少必填参数 "path"`；必填项为 null：`参数 "path" 不能为 null`；
- 类型不符：`参数 "path" 期望 string|integer|number|boolean|array|object`（number 接受整数）；
- 枚举：非字符串 `参数 "path" 期望 string 枚举`；取值越界 `参数 "path" 取值不在 [values] 内`；
- 数组：逐元素递归（路径 `path[i]`）；元素为 null 仅当元素声明 required 时违规（`参数 "path[i]" 不能为 null`）；
- 对象：按声明的嵌套字段递归（路径 `path.child`）；未声明的额外字段不校验。

## 6. 执行管线（ToolRegistry.call）

`校验 → 守卫 → 中间件链 → 执行体 → 广播`，失败一律收敛为失败结果，不向外传播：

1. 未知工具：`UNKNOWN_TOOL`，content `未知工具 "name"`，error `unknown tool "name"`；
2. 参数违规：`INVALID_ARGS`，content `参数不合法：v1；v2`（全角分号连接），error 为 `; ` 连接；
3. 守卫：按登记顺序，首个非空理由即 `TOOL_DENIED`（理由同时作 content 与 error）；
4. 中间件链：**先注册者为最外层**（后进先出包裹执行体）；
5. 执行体异常（含中间件抛出）：`TOOL_ERROR`，content 与 error 均为错误的展示串；
6. 超时：`TOOL_TIMEOUT`，content `工具 "name" 超时（Nms）`，error `name timed out`；
7. 结果确定后，向结果观察者快照广播（逐个调用，观察者增减不影响当次）。

## 7. 超时优先级

`调用参数 timeout` > `Tool.timeout` > `注册表 defaultTimeout`；三者皆空则不限时。

## 8. 注册与监听

- `register`：同名重复注册抛错（`工具 "name" 已注册`）；返回幂等 Disposer，撤销时若键位已被更替则不误删新值。
- `names` 按注册顺序；`describe()` 全量白名单投影；`describeOne(name)`。
- `guard` / `use` / `onChange` / `onResult` 均返回幂等撤销函数；变更监听器在注册/注销后触发（快照）。

## 9. fn 与分组

- `tools.fn(name, description:, params:, riskLevel:, group:, pathParams:, handler:)`：一行注册闭包工具，与类工具同管线。
- `tools.group(name, tools)`：整组注册（同组重名或与既有重名抛错），撤销函数一次性注销整组（逆序）。
- `groups`（首次出现顺序）、`groupOf(name)`（分组登记优先，`Tool.group` 兜底）、`namesIn(group)`、`describeGroup(group)`、`describeWithin(maxRisk)`（只投影风险不高于上限的 schema）。
- `guardRisk(maxRisk)`：能力分级守卫，越级拒绝消息 `工具 "name" 风险等级 X 高于允许的 Y`。

## 10. 装配

`provideTools(ctx, tools:, timeout:)`：以 `'tools'` 服务键提供注册表；`ctx.tools` 快捷访问。

## Swiftus 实现注记（偏离记录）

- 动态参数统一 `JSONValue`；`ToolContext` 用**类型化访问器**（string / requireString / integer / number / boolean / array / object）替代 Dart 的泛型 `optional<T>` / `require<T>`——缺失 / null / 类型不符的消息语义保留，「实际类型」以 JSONValue 形态名呈现。
- 监听与中间件的移除由闭包身份改为**令牌**（同 S1 注记）。
- 分组登记存于注册表实例内部（Dart 用 Expando 外挂，语义相同）。
- 超时引擎暂用 Task.sleep（系统钟）；Clock 统一纪律落地（方案书 §5.5）时回接。
- `Tool` 为协议 + 默认实现（Dart 为抽象基类）；`call` 为 async throws，异常由注册表按 §6.5 收敛。
